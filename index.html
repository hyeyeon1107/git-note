따라 해보기 · 처음부터 push까지

# 1. 폴더를 저장소로 만들기
git init
# 2. 작성자 정보 (PC에서 최초 1회)
git config --global user.name "홍길동"
git config --global user.email "me@example.com"
# 3. 파일 수정 후 상태 확인 → 올리기 → 저장
git status
git add .
git commit -m "첫 커밋"
# 4. GitHub 연결 후 업로드 (최초 1회)
git remote add origin https://github.com/아이디/저장소.git
git push -u origin main
# 5. 이후 반복: 수정 → add → commit → push
git add .
git commit -m "내용 수정"
git push

vi 모드 전환

명령 모드열면 여기서 시작 · :wq / :q / :q!
입력하려면명령으로
입력 모드글자 입력 가능
글자가 안 써지면 명령 모드예요. i를 누르세요. 저장하려면 esc 후 :wq.

따라 해보기 · 폴더 만들고 메모 쓰기

pwd                  # /home/user
mkdir -p study/day1  # study 안에 day1까지 생성
cd study/day1
touch memo.txt
cat > memo.txt       # 입력 후 Ctrl + D
cat >> memo.txt      # 끝에 이어 쓰기, Ctrl + D
cat memo.txt         # 내용 확인
vi memo.txt          # i → 수정 → esc → :wq
ls -al               # 숨김 파일까지 상세 목록
cd ..                # study로 올라가기
rm -r day1           # 폴더째 삭제 (복구 불가)
